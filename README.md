# BlackBean Studio Web Portal (COWSAP v1.5 & RooCozy v2.2 Hoàn Thiện)

Cổng thông tin & phát hành chính thức của **BlackBean Studio** (CEO `baebless`):

- `index.html` — Trang chủ giới thiệu **COWSAP v1.5** và **ROO – My Little Café (RooCozy v2.2)**.
- `roo.html` — Trang sản phẩm chuyên biệt cho **RooCozy v2.2** (ảnh gameplay, 25 nhân vật, changelog v1.2→v2.2, tải đa nền tảng).
- `roocozy.html` — Bản game đầy đủ **RooCozy v2.2 Hoàn Thiện** (chơi trực tiếp trên Web/PWA, không cần cài đặt).
- `icon.png`, `manifest.json`, `og-banner.png`, `_headers` — Tài nguyên PWA, ảnh xem trước chia sẻ Zalo/Facebook và cấu hình bảo mật Netlify.

## Cập nhật lên Web
- **Netlify:** Giải nén `BlackBean-Web-v2.2.zip` và kéo thả toàn bộ thư mục vào Netlify Drop / Deploys.
- **GitHub Pages (`electricshu/blackbean-web`):** Ghi đè toàn bộ các tệp vào nhánh `main` và commit.
